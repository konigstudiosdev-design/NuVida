### Versión Web (PWA)
Puedes acceder al sistema en la nube o instalarlo en Windows/Android directamente desde el navegador a través de nuestro enlace oficial:
👉 **[Visitar Sistema Web](https://app.nuvida.konigstudios.com)** *(Sustituir con tu enlace final de Vercel)*
